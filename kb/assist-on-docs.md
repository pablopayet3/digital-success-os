# Use Relay Assist on documents and boards

Relay Assist works on both Relay Boards and Relay Docs. On a card or a board, it can summarise the discussion, draft a status update, or find related cards. On a document, it can summarise the page, draft a first version from a few bullet points, or answer a question using the documents you have access to.

Assist only reads content the person asking is allowed to see. It needs the Relay Assist add-on, which is available on Standard, Premium and Enterprise.
