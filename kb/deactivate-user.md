# Remove or deactivate a user

When someone leaves, an admin can deactivate them under Admin settings, Users. Find the person, open the menu at the end of the row and choose Deactivate.

Deactivating frees the seat at once. The person's cards, comments and documents stay where they are, and cards assigned to them show as unassigned. You can reactivate a user later and they get their history back.

Deleting a user permanently is only possible on request to support, because it cannot be undone.
