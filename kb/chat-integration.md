# Chat integration keeps disconnecting

The chat integration posts card updates to a channel of your choice. If it disconnects every few days, the approval was given by a user whose chat account signs out regularly, or who has since been deactivated.

Fix: an admin with a permanent chat account should disconnect the integration under Admin settings, Integrations, Chat, and connect it again with their own account. Use a shared service account if your chat tool supports one.
