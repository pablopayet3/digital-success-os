# An automation rule did not run, or runs twice

If a rule did not run, open the Automation panel on the board and look at the rule's run history. The most common causes are: the rule is switched off; the trigger is on a different list than the one the card moved to; or a condition (label, assignee) did not match.

If a rule sends two notifications for every card, two rules have the same trigger. Check for a copy of the rule on the board and in the workspace template the board was created from. Switch one of them off.
