# Reuse a board layout with templates

If every new project should start from the same layout, turn a board into a template. Open the board, choose the menu at the top right, then Save as template. Give it a name. Lists, labels, automation rules and checklist items are saved; cards are saved only if you tick Include cards.

To use it, click New board and pick the template under Your templates. Admins can mark a template as the default for the whole workspace under Admin settings, Boards.
