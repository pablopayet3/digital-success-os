# Setup checklist: the four steps to get started

New to Relay, or stuck on setup? These four steps get a workspace ready. Teams that finish them in the first weeks get far more out of Relay.

1. Create your first board. Pick a template and add a few real cards. See "Create your first board".
2. Invite at least five people. Boards are only useful with your team on them. See "Invite your team" or "Invite many users at once".
3. Connect an integration. Chat or calendar are the quickest wins. See "Connect an integration".
4. Configure single sign-on (Standard, Premium and Enterprise). See "Set up single sign-on (SSO)".

Admins can see which steps are done under Admin settings, Setup progress. If you are not sure what to do next, start with the first step on this list that is not done yet.
