# Export a board to a spreadsheet

To export a board, open it, choose the menu at the top right, then Export, then CSV. The file has one row per card with its list, title, assignee, labels, due date and the date it was last changed. Archived cards are included only if you tick Include archived.

For a monthly report, save the export with the same filter each time, or connect the cloud drive integration to have the export written to a shared folder automatically.
