# Show commits on cards (code repository integration)

The code repository integration links commits and pull requests to cards. Connect it under Admin settings, Integrations, Code repository, and choose which repositories Relay may read.

To link work to a card, include the card's short ID (for example RLY-142) in the commit message or the pull request title. The commit then appears on the card, and the card moves to the list you chose under Integration settings when the pull request is merged.
